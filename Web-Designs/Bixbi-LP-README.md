Bixbi Landing Page

The Bixbi Landing Page is a sleek and modern design concept created to explore layout balance, color harmony, and visual flow. It reflects a minimal yet confident brand identity, blending clean typography with subtle interactive elements — all crafted in Figma.

⸻

🎨 Overview

This project focuses on showcasing:
	•	A bold hero section with clear call-to-action
	•	Consistent grid alignment and spacing
	•	Smooth color transitions and aesthetic contrast
	•	Intuitive user flow and responsive layout planning

⸻

🧠 Built With
	•	Figma (UI/UX Design)
